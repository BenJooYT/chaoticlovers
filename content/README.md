# content

Placeholders for the sections we plan to build. Empty on purpose — the folders exist so the shape of the site is visible before any stack is picked.

- `memories/` — time capsule: photos, notes, dated moments.
- `journal/` — shared journal entries.
- `writing/` — blogs, stories, poems.
- `milestones/` — anniversaries, counters, upcoming dates.
- `playground/` — mini games and interactive toys.

Delete or rename any of these once the real structure settles; nothing depends on them yet.
